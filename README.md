# AI Course: LangChain and LangGraph

Ejemplos prácticos para aprender a desarrollar aplicaciones de inteligencia
artificial con LangChain y LangGraph.

## Configuración local

1. Crea y activa un entorno virtual de Python.
2. Instala las dependencias con `pip install -r requirements.txt`.
3. Configura `OPENAI_API_KEY` como variable de entorno del sistema.

Los archivos `.env`, credenciales OAuth, tokens, claves privadas, entornos
virtuales y bases vectoriales generadas están excluidos mediante `.gitignore`.
Usa `.env.example` únicamente como plantilla y nunca publiques claves reales.

Los PDF de contratos usados como datos locales para los ejercicios RAG tampoco
se publican. Coloca tus documentos en `Tema_3/Contratos/` o
`Tema_3.1_RAG/documentos/` y conserva allí solamente copias locales autorizadas.
