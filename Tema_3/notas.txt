Un Document Loader (cargador de documentos) es una herramienta que extrae texto y metadatos de archivos en diferentes formatos para que puedan ser procesados por una Inteligencia Artificial.Es el primer paso en el flujo de trabajo de aplicaciones como los sistemas RAG (Recuperación Aumentada por Generación).¿Cuál es su función principal?Los Modelos de Lenguaje (LLMs) solo entienden texto plano, pero las empresas guardan su información en formatos muy diversos. El Document Loader se encarga de:Conectar: Acceder a la fuente de origen (un archivo local, una base de datos o una API en la nube).Extraer: Leer el contenido ignorando el código o formato propietario.Normalizar: Convertir todo ese contenido en un formato estándar de texto limpio estructurado, listo para el Text Splitter.Tipos comunes de Document LoadersDependiendo de dónde esté la información, se utilizan diferentes cargadores:Archivos locales: Para extraer texto de PDFs, documentos de Word (.docx), hojas de cálculo (.csv, .xlsx), presentaciones o archivos de texto plano (.txt).Páginas web: Para hacer web scraping y extraer el contenido limpio de URLs, blogs o documentación en línea (HTML, Markdown).Servicios en la nube: Conectores específicos para plataformas como Google Drive, Notion, SharePoint, Confluence o Slack.Bases de datos: Cargadores que ejecutan consultas en bases de datos SQL o NoSQL y transforman los registros en documentos de texto.El flujo completo en IAPara entender dónde encaja, este es el orden técnico en el que interactúan:Document Loader: Toma un PDF de 100 páginas y lo convierte en un solo bloque de texto limpio.Text Splitter: Corta ese bloque de texto en 200 chunks pequeños de 500 palabras cada uno.Vectorization/Embeddings: Convierte esos chunks en números para que la IA los pueda buscar eficientemente.
